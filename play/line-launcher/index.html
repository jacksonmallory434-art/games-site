Line Launcher

Algebra All games

About this game

Aim a laser using y = mx + b. Set the rise, the run, and the y-intercept so your line passes through every star, and plan around the walls.

How to play

Use the + and − buttons to set rise, run and b, then fire. The laser stops at walls. Hit every star in the fewest lines for three stars.
